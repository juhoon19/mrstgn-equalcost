# 压测记录

环境：一台 4 核云容器，**分片、网关和压测机器人全部挤在同一台机器上**。真实部署中机器人在别处，服务器数字只会更好。

机器人（`bench/bots.js`）行为：视口 900×520 世界单位缓慢漂移（相当于 1800×1040 屏幕、2 倍缩放），光标 5 次/秒，工具 0.2 次/秒，偶尔聊天，每 2 秒 ping。一部分机器人完整解码快照流，统计协议错误：

- `unknownIds`：增量里出现本流不认识的 id（真正的失步）
- `dupAdds`：重复新增
- `gaps`：帧号跳跃（只在背压丢帧后出现，之后从关键帧恢复）

## 1. 消息合并前后（1 网关，2 分片，24×24 世界）

| | 合并前 | 合并后 |
|---|---|---|
| 成功连接 | 660 / 1000（其余卡在握手） | **1000 / 1000** |
| 网关 CPU | 90% | **37%** |
| 网关出口 | 11.3 MB/s | **37.7 MB/s** |
| 网关发送消息数 | 87 000 /s | 13 700 /s |
| RTT p50 / p95 / p99 | 614 / 2104 / 2622 ms | **1 / 15 / 16 ms** |
| unknownIds / dupAdds | 0 / 0 | 0 / 0 |

## 2. 横向扩展（2 网关，2 分片，4 个机器人进程共 2000 人）

| 指标 | 数值 |
|---|---|
| 连接分布 | 网关 A 999，网关 B 1001（cluster 轮询） |
| 总出口 | 93 MB/s（≈ 750 Mbit/s） |
| 每人下行 | ≈ 47 KB/s（视野内平均 ~1700 个实体，机器人一直在播种，很密） |
| RTT | p50 9–12 ms，p95 48–75 ms，p99 83–112 ms |
| 失步 | 0 |
| 网关 CPU | 各 ≈ 40% |
| 模拟 | 2000 个机器人把种群推到 23 600；每分片 1 万实体，tick 41 ms，时间流速降到 73%（时间膨胀按设计生效，未卡死） |

## 3. 带宽优化历程（每人，~450 实体在视野内）

| 步骤 | KB/s |
|---|---|
| 初版：移动记录每实体 ~8 字节，化学场 16×16、2Hz（场占 46%） | 63 |
| 移动记录 id 差分 + 标志位、半径/等级仅变化时发送、位置 1/8 量化；化学场下采样 8×8、1Hz（两项一起测） | **19** |

之后又把纯光标更新降到 5Hz、概览降到每 2 秒一次（未单独测量收益）。

**低频档**（缩小视图用，同样视口，40 个全解码机器人，不播种）：

| 档位 | 每人 KB/s | 其中实体 |
|---|---|---|
| 高档 10 Hz | 19.4 | 13.3 |
| 低档 2.5 Hz | **11.1** | **5.2** |

低档里化学场和概览成了大头（合计约 50%），可以按需再降。

当前字节构成（密集场景）：实体 ~64%，光标/聊天/特效 ~20%（机器人光标很多），化学场 ~10%，概览 ~5%。

## 4. 模拟性能（`bench/headless.js`，单分片 12×12 区块，约 2800 个生物）

| 版本 | ms/tick |
|---|---|
| 初版 | 12.45 |
| 场扩散改为带边界环的模板 + 光照缓存 + 化学每 2 tick 一步 | 6.90 |
| 神经网络/感知去掉每次分配 | **6.35**（≈ 2.3 µs / 生物 / tick） |

优化前后同一随机种子下种群曲线完全一致（逐位相同的生物数），说明优化没有改变行为。

## 5. 容器化部署验证

`deploy/docker-compose.yml`：4 个分片容器（2×2 分区，覆盖角落对角交接）+ 网关容器，全部通过 Docker 服务名互联。14 个全解码机器人 40 秒：0 失步，RTT p50 1 ms。（沙箱无法访问 Docker Hub，测试时基础镜像用本机 Node 二进制手工导入；正式构建用 Dockerfile 里的 `node:22-alpine`。）

## 复现

```bash
MAX_PER_IP=100000 scripts/dev-bg.sh --shards 2 --gateways 2 --world 24x24
for i in 1 2 3 4; do node bench/bots.js --n 500 --duration 80 --decode 0.02 > .run/bots$i.log & done
curl localhost:8080/metrics; curl localhost:9100/metrics
scripts/dev-stop.sh
```
